2. Problem and decision statement
The main problem and decision statement is “Identifying how security analytics can be used to detect
and prioritise anomalous IIoT, network and remote-user behaviour in a simulated mining remote-
operations environment”.

To monitor and manage operations, mining operations depend more on networked equipment, industrial
Internet of Things (IIoT) devices, remote access and central control services. Although these technologies
facilitate effective remote operations, the way they interconnected makes it possible for unauthorized
access, anomalous network/device behavior and credential abuse. Unusual communication between
devices, compromised remote-user credentials, anomalous sensor activity and other deviations from
standard operating procedures can all be the source of suspicious behavior.

This project will focus primarily on IIoT telemetry, network-flow data and remote-user activity which will
be analysed to establish normal behavioural patterns and identify significant deviations that may indicate
potential security concerns. The main stakeholders affected are mining security personnel, IT ,network
administrators, remote-operations personnel and operational managers as they require understandable
analytical information that can assist them in determining which users devices or network events require
further investigation.

The project also aims to identify which remote users, IIoT devices or network events should be prioritised
for security investigation based on detected anomalous behaviour and associated risk and will be
answered as the project progresses. A small segmentation simulation will additionally be used to
demonstrate how network segmentation may affect the potential spread or impact of suspicious activity.
This simulation will be performed in an authorised or simulated environment and will not involve testing
live mining infrastructure.
